## 会员约束的证据范围

授权场景分为两层，没有把模拟服务当成生产服务器实测：

1. **正式后端源码的隔离测试**：实际发布后端的 40 项测试，以及使用真实发布客户端授权类的 3 项跨设备联测，均通过。涵盖并发登录只绑定一台、同设备新会话撤销旧会话、退出仍保留设备绑定、店主解绑撤销会话并保留会员到期时间、停用/过期/密码变更、付款回调幂等和退款对应处理。
2. **Windows 客户端实际运行**：原包先保持正式配置完成公钥/DPAPI 自检；随后仅将临时测试副本的公开授权配置指向一次性的本地 HTTPS 协议模拟器，验证首次七天、续费三十天、第二台收到设备限制后的拒绝行为、授权换机、到期拦截。模拟器使用生成的测试签名密钥和 `example.invalid` 测试账号，结束后恢复原配置。生产后端、生产签名密钥、真实会员和真实支付记录未被修改。

已发布客户端另有 37 项组件测试通过，覆盖授权签名、时间回拨、重启必须联网、短时离线限制、权限和批准、连接恢复及故障摘要脱敏。本地测试合计 80 项通过；这些本地测试不等同于 Windows 实机运行，已与上表分别列出。

## 发现与边界

- 美国测试机的单连接整包下载约 0.55 MB/秒，先前运行因此超时。改用下载服务原本支持的 HTTP Range 并发获取、完整重组并校验 SHA-256；本次两台分别用约 10.7 秒和 11.4 秒完成。未修改商店生产下载接口。普通浏览器的单连接跨地区下载速度仍可能较慢。
- 原测试证书配置阶段曾超时，已改为在临时云端机器上生成内存证书并使用机器测试信任。用户自己的电脑未安装这些测试证书。
- 不是 Win10/Win11 所有消费版、所有杀毒软件/SmartScreen、家庭网络以及每一种 AI 网页的全面兼容认证。当前结果证明上述两个独立 Windows 环境中，当前安装版所列功能可用。
- 会员按账号并绑定一份设备密钥；DPAPI 限制普通复制分享。它不是无法破解的硬件 DRM。运行中的短时离线凭证最长一小时，在线撤销在下次联网核验或凭证到期时生效；凭证自身不会超过会员到期时间。新进程启动必须联网。
- 未新增真实付款、退款、提现或结算操作。此前平台次日结算问题不属于这次 Windows 验收结论。
